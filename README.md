# Java アンチパターン クイズ

Java のコードサンプルからアンチパターンになっている行を見つける、フロントエンド完結のクイズアプリです。

## 特徴

- サーバー不要（静的ファイルのみで動作）
- **難易度別 90 問**（初心者 / 中級者 / 上級者 各 30 問）
- トップ画面で難易度を選択
- 行をクリックして回答（同種の問題が複数行なら代表1行でも正解）
- 回答後に解説と正解行のハイライト表示
- ヒント機能付き

## 採点の考え方

完全一致は求めません。**正解行を1行以上選び、関係のない行を選んでいなければ正解**です。
同種のアンチパターンが複数ある場合は、回答後にほかの該当行も表示されます。

## 難易度

| 難易度 | 内容例 |
|--------|--------|
| 初心者 | `==` 比較、マジックナンバー、例外の握りつぶし など |
| 中級者 | リソース未クローズ、SQL インジェクション、Raw Type など |
| 上級者 | InterruptedException、ダブルチェックロッキング、ThreadLocal など |

## セットアップ

```bash
npm install
```

## 開発サーバー起動

```bash
npm run dev
```

ブラウザで表示された URL（通常 `http://localhost:5173`）にアクセスしてください。

## ビルド（静的ファイル生成）

```bash
npm run build
```

`dist/` フォルダに静的ファイルが生成されます。任意の Web サーバーや GitHub Pages などにデプロイできます。

```bash
npm run preview
```

## 技術スタック

- TypeScript
- Vite
- バニラ DOM（フレームワーク不使用）

## 開発ルール

**問題の理不尽さを感じさせないこと**をこのプロジェクトの最優先ルールとする。

クイズ問題の追加・変更時は `.cursor/rules/quiz-fairness.mdc` に従い、説明文・正解行・解説の整合、行選択形式との相性を必ず確認すること。
